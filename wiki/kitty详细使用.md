
| 操作          | 默认快捷键                  |
| ----------- | ---------------------- |
| 复制选中文字      | `Ctrl+Shift+C`         |
| 粘贴剪贴板       | `Ctrl+Shift+V`         |
| 新建内部终端分屏    | `Ctrl+Shift+Enter`     |
| 关闭当前分屏      | `Ctrl+Shift+W`         |
| 新建独立桌面窗口    | `Ctrl+Shift+N`         |
| 新建标签页       | `Ctrl+Shift+T`         |
| 关闭当前标签页     | `Ctrl+Shift+Q`         |
| 切换到前／后一个标签页 | `Ctrl+Shift+←` / `→`   |
| 切换到前／后一个分屏  | `Ctrl+Shift+[` / `]`   |
| 切换分屏布局      | `Ctrl+Shift+L`         |
| 调整分屏大小      | `Ctrl+Shift+R`         |
| 放大字体        | `Ctrl+Shift+=`         |
| 缩小字体        | `Ctrl+Shift+-`         |
| 恢复配置中的字号    | `Ctrl+Shift+Backspace` |
